{%- comment -%} Erklärung für tote Links (Markdown: [Text](url){: .link-tot}) unten auf der Seite. Liest die Links aus dem fertigen HTML: kramdown schreibt Text. Pro Link: alte Adresse + „neuen Link suchen“ (Suche nach der alten Adresse). Aufruf: {% include link-tot-hinweis.html html=content %} {%- endcomment -%} {%- assign teile = include.html | split: 'class="link-tot"' -%} {%- assign anzahl = teile.size | minus: 1 -%}

🪦 = Dieser Link funktioniert nicht mehr (die Seite ist offline oder wurde entfernt). Wir lassen ihn stehen, damit nachvollziehbar bleibt, worauf sich der Text bezieht.

    {%- for i in (1..anzahl) -%} {%- assign vorher = teile[forloop.index0] -%} {%- assign url = vorher | split: 'href="' | last | split: '"' | first -%} {%- assign roh = url | replace: '&', '&' -%} {%- assign text = teile[i] | split: '' | first | split: '>' | last | strip_html | strip -%}
  • {% if text != roh %}{{ text }}: {% endif %}{{ url }} – neuen Link suchen · alte Version im Internet Archive
