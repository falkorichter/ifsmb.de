# Changelog

Alle nennenswerten Änderungen an den **Funktionen** von ifsmb.de stehen in dieser Datei. Neue oder geänderte Inhalte (Beiträge, Termine, Projekte, Profile, Geräte, Partner, Pressemitteilungen, Textseiten) stehen hier nicht – was wann dazukam, zeigen das [Netzwerk](https://ifsmb.de/netzwerk/) und seine Zeitleiste.

Das Format basiert auf [Keep a Changelog](https://keepachangelog.com/de/1.0.0/). Die Seite hat keine Versionsnummern: Jeder Abschnitt ist ein Tag, an dem Änderungen live gegangen sind (Datum im Format JJJJ-MM-TT).

- **Direkt bearbeiten: Konflikte im Browser lösen.** Bevor das ✏️/➕-Formular etwas sendet, liest es den aktuellen Stand (`main` oder den Branch des Pull Requests) neu und führt zusammen (`assets/js/merge.js`: Front Matter pro Feld, Listen wie `tags`/`team` als Mengen, Text zeilenweise). Was sich nicht überschneidet, wird automatisch übernommen; sonst zeigt eine Konfliktbox pro Feld bzw. Textstelle „Meine Version / Neuere Version / Beide“ – es wird nichts mehr still überschrieben. Nach dem Senden bleibt das Formular im Pull Request („🚀 In #N speichern“); ein eigener offener PR wird automatisch fortgesetzt, „In #N mitschicken“ übernimmt schon Eingetragenes, gemergte/geschlossene PRs und neue PRs anderer während des Schreibens werden erkannt (mit Optionen). Entwürfe werden auf den neuen Stand übertragen statt gelöscht, Fotonummern berücksichtigen offene PRs, ein unterbrochenes Senden wird beim nächsten Klick fortgesetzt, fehlende Fotos im Text werden erkannt. ### Geändert

- **Projekt-Ideen unter `/project/ideas/`:** Die Ideen-Sammlung ist eine statische Seite und keine Collection und liegt deshalb nicht mehr unter `/projects/`. `/projects/ideas/` und `/projekte/ideen/` leiten weiter.
- **Ordner `_challenges/` statt `_herausforderungen/`:** Die Collection der Herausforderungen heißt jetzt `challenges` (`site.challenges`), passend zur Adresse `/challenges/`.
